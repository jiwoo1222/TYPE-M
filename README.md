# TYPE-M

흥미 설문으로 일반 전공과 기능반 분야를 비교하는 브라우저 앱입니다.

## 실행

저장소를 내려받아 `index.html`을 브라우저에서 열면 됩니다.
별도의 패키지 설치나 빌드 과정은 없습니다. 로컬 HTTP 서버나 정적 호스팅에서도 실행할 수 있습니다.

## 구성

- `index.html`: 소개 문구, 검사 카드, 특징 안내
- `styles.css`: 데스크톱·모바일 화면과 키보드 포커스 스타일
- `app.js`: 검사 진행, 결과와 저장 목록, 백업 화면
- `assessment-data.js`: 분야 설명, 체험 과제, 검사 문항
- `assessment.js`: 응답 검증, 점수 계산, 동점 해설
- `result-store.js`: 결과 검증·저장·삭제·백업
- `draft-store.js`: 진행 중 응답 임시 저장
- `view.js`: DOM 생성, 포커스 이동, 파일 다운로드

이용 안내 링크와 우측 하단 안내 버튼은 특징 안내 영역으로 이동합니다.
일반 전공은 12문항, 기능반은 10문항입니다. 각 문항에 1~5점으로 응답하고 이전 문항으로 돌아가 수정할 수 있습니다.
응답과 위치를 자동으로 임시 저장하며, 홈의 **검사 이어 하기**로 재개합니다. 검사가 끝나면 임시 응답을 정리합니다.
결과 화면에서 분야별 흥미 점수와 설명, 체험 과제를 확인하고 저장·복사·인쇄할 수 있습니다.
JavaScript가 꺼져 있으면 검사에 JavaScript가 필요하다는 안내를 표시합니다.
글꼴은 Pretendard CDN에서 불러오며, 연결되지 않으면 기본 sans-serif 글꼴을 사용합니다.

## 점수와 저장

각 분야에 문항 2개를 동일하게 배정합니다. 합산 점수를 `(합계 - 문항 수) / (문항 수 × 4) × 100`으로 환산합니다.
동점 분야는 함께 설명합니다. 모든 점수가 같으면 특정 분야를 임의로 추천하지 않습니다.
결과는 자기 보고한 흥미의 비교이며 검증된 적성 진단이나 AI 모델의 추론 결과가 아닙니다.

로그인과 서버는 사용하지 않습니다. 응답·결과는 현재 브라우저에만 저장합니다.
결과는 최대 50개이며, 가득 차면 이전 결과를 자동 삭제하지 않고 정리를 안내합니다.
같은 기기를 함께 쓰면 저장된 결과를 볼 수 있으므로 필요한 결과만 남겨두세요.
다른 탭에서 결과를 바꾸면 목록도 갱신합니다. 검사 중인 응답을 여러 탭에서 동시에 바꾸면 마지막 임시 저장이 남습니다.

저장된 결과에서 **결과 백업 내보내기**로 JSON 파일을 받습니다.
**결과 백업 가져오기**는 1MB 이하의 TYPE-M 백업을 검증한 뒤 기존 결과와 합칩니다.
같은 ID의 결과는 중복 추가하거나 덮어쓰지 않습니다. 형식 오류나 50개 초과 시 기존 저장 데이터를 유지합니다.
다른 브라우저로 옮기거나 사이트 데이터를 지우기 전에 백업하세요.

## 변경 확인

Node.js가 있으면 `node --test *.test.cjs`로 점수·결과 저장·백업·임시 저장 회귀 테스트를 실행합니다.
브라우저에서는 두 검사 완료, 무응답 차단, 이전 문항 수정, 새로고침 후 재개, 결과 저장·삭제·필터를 확인합니다.
백업 왕복, 잘못된 파일 안내, 클립보드 거부 시 직접 복사, 인쇄와 320px 화면도 확인합니다.
