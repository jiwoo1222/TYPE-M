# TYPE-M

전공 추천 서비스 TYPE:M의 정적 소개 화면입니다.

## 실행

저장소를 내려받아 `index.html`을 브라우저에서 열면 됩니다.
별도의 패키지 설치나 빌드 과정은 없습니다.

## 구성

- `index.html`: 소개 문구, 검사 카드, 특징 안내
- `styles.css`: 데스크톱·모바일 화면과 키보드 포커스 스타일

이용 안내 링크와 우측 하단 안내 버튼은 특징 안내 영역으로 이동합니다.
로그인, 검사 시작, 결과 저장은 아직 연결되지 않은 화면 요소입니다.
글꼴은 Pretendard CDN에서 불러오며, 연결되지 않으면 기본 sans-serif 글꼴을 사용합니다.
